## What it does

Write one Markdown file → run one command → get everything ready to upload to KDP.

```
book.md  ──►  50 B&W interior pages (2550×3300 px, 300 DPI)
         ──►  Front & back cover images
         ──►  Lossless interior PDF (8.5 × 11 in)
         ──►  upload_details.txt  (every KDP form field, copy-paste ready)
```

Images are generated by the **OpenAI Images API** (`gpt-image-1`), auto-QA'd, and post-processed to print-ready B&W PNGs — all resumable if the run is interrupted.

---

## Features

| | |
|---|---|
| 🎨 **AI image generation** | `gpt-image-1` with parallel workers (default 3) |
| 🔍 **Automatic QA** | Flags grey shading, too-empty, too-filled, cropped, background noise — retries with corrective prompts |
| 🖨️ **Print-ready output** | 2550 × 3300 px pure B&W PNGs, Lanczos upscale, hard threshold |
| 📄 **Lossless PDF** | img2pdf at exactly 8.5 × 11 in, "This Book Belongs To" page, blank-page interleaving |
| 🖼️ **Cover generation** | Front, back, and optional colored sample images |
| 📋 **KDP upload details** | All listing fields, spine width, cover dimensions, AI-disclosure reminder, pre-upload checklist |
| ▶️ **Resume mode** | `manifest.json` tracks every page — re-run safely after a failure or interruption |
| ✅ **Metadata validation** | Title length, keyword limits, HTML tag whitelist, brand name blacklist |
| 🌐 **Arabic + table support** | Markdown tables and Arabic section headings both parsed correctly |

## Quick Start

### 1 · Clone and install

```bash
git clone https://github.com/Dabash99/KDP-Creator.git
cd KDP-Creator
pip install -r requirements.txt
```

### 2 · Add your OpenAI key

Create a `.env` file next to `kdp_book_builder.py`:

```
OPENAI_API_KEY=sk-...
```

> The key is never printed, logged, or committed. `.gitignore` already excludes `.env`.

### 3 · Run

```bash
# Dry run — parse, validate, write upload_details.txt (no API calls)
python kdp_book_builder.py "path/to/book.md" --dry-run

# Test with the first 2 pages only
python kdp_book_builder.py "path/to/book.md" --limit 2 --yes --skip-samples

# Full production run
python kdp_book_builder.py "path/to/book.md" --yes
```

## CLI reference

```
python kdp_book_builder.py <book.md> [options]
```

| Flag | Default | Description |
|---|---|---|
| `--out PATH` | `D:\KDP` | Root output folder |
| `--yes` | — | Skip the "Proceed?" confirmation |
| `--limit N` | 0 (all) | Generate only the first N pages |
| `--regen 7,12` | — | Force-regenerate specific page numbers |
| `--skip-cover` | — | Skip cover generation |
| `--skip-samples` | — | Skip colored-sample generation |
| `--author "Name"` | from MD | Override author in `upload_details.txt` |
| `--model ID` | `gpt-image-1` | OpenAI image model |
| `--quality` | `medium` | `low` / `medium` / `high` |
| `--size` | `1024x1536` | Image size |
| `--workers N` | `3` | Concurrent generation threads |
| `--threshold N` | `140` | B&W threshold for post-processing (0–255) |
| `--dry-run` | — | Parse + validate + write details, **no API calls** |
| `--only-pdf` | — | Rebuild PDF from existing processed images |

## Markdown file format

See [`tests/fixtures/sample_book.md`](tests/fixtures/sample_book.md) for a full working example.

Sections are matched **case-insensitively** and support both English and Arabic headings:

| Section | Content |
|---|---|
| `## Master Style Prompt` | Fenced code block — the base illustration style sent with every page prompt |
| `## Page Ideas` | Numbered list of page ideas (one per line) |
| `## Cover` | Sub-sections `### Front Cover`, `### Back Cover`, `### Colored Sample` each with a code block, **or** 3 ordered code blocks directly under `## Cover` |
| `## KDP Details` | Key–value fields (or a Markdown table) + sub-sections: `### Description`, `### Keywords`, `### Categories` |

KDP fields parsed: Book Title, Subtitle, Author, Reading Age, Language, Series, Edition, Contributors, Publishing Rights, Sexually Explicit Content, Primary Marketplace, Low-content notes, Paper, Interior, Trim, Bleed, Cover Finish, Pricing, Categories.

## Tests

```bash
pytest tests/test_parser.py -v
```

The test suite runs the parser against the real book-01 Markdown file (auto-skipped if the file isn't present) and verifies all 50 page ideas, 7 keywords, cover prompts, every KDP metadata field, and error-message quality for malformed input.

## Blacklist

Edit [`blacklist.txt`](blacklist.txt) to add brand or character names. Any match in the title, subtitle, description, or keywords prints a warning before upload.

openai>=1.40.0

## Security

- API key loaded from `.env` via `python-dotenv` — never hardcoded, printed, or logged
- `.env` is in `.gitignore` and will never be committed
- All 4xx API errors (except 429 rate-limit) fail immediately — no key exposure through retries
